# 1st_half

First-half tactical templates and a turn-based **解防守題** board game.

## 解防守題（推薦用網頁 UI）

文字規則：

- 電腦模擬版（格線自動截傳／擋射）：[`GAME_RULES.md`](GAME_RULES.md)
- 實體棋盤版（傳球／射門由場上真人執行）：[`PHYSICAL_GAME_RULES.md`](PHYSICAL_GAME_RULES.md)

```bash
python play_web.py
```

瀏覽器打開 `http://127.0.0.1:8765/`：選關 → 選行動 → 點棋盤目標。左側有「提示／正解示範／重開本關」。

### 場地與計分

- 棋盤 **7×8**：短邊（寬 7）是球門邊，長邊（深 8）是進攻方向；球門三格 `(2,7)(3,7)(4,7)`
- 回合制，每關通常最多 **8** 回合；越快進球分數越高（`11 − turns`，上限 10）

### 進攻回合（軟階段）

- **無球跑位 `move`**、**盤帶 `dribble`**：同回合可繼續跑位／傳球；**防守者不動**
- 盤帶後同回合：**不能再盤帶、不能射門**；可跑其他人或傳球
- 本回合已做無球跑動：**不能盤帶／射門**——先 **結束回合** 或傳球
- **結束回合 `end`／地滾傳 `pass`／高空傳 `lob`**：防守者才反應（全員跟上）

### 傳球與射門

- **地滾傳球**：路線中途格有**任一**防守者 → 被斷
- **高空傳球**：飛越地面攔截
- **射門**：必須在前場（`y ≥ 4`）；射門線上有防守者會被擋／門將撲出
- 射門當下以當下站位判定（傳球後防守已先跟上再輪到你射）

### 防守角色（AI）

| 角色 | 行為 |
|------|------|
| 逼搶 Presser | 每拍朝球衝最多 **2** 格；已貼身時結束回合／硬射可能被斷 |
| 大閘 Block | 鎖在自己的橫線，沿「球→球門中心」走廊橫移 1 格；可截傳、擋射 |
| 影子 Shadow | 黏一名進攻者；反應時朝**門側**（人與球門之間）走 1 格，不站到人前面 |
| 攔截 Interceptor | 卡最危險的地滾傳切線 |
| 門將 GK | 球門線上每拍朝**球的縱向**滑 1 格（遠近都追） |

定點大閘（`anchored`）不移動，用來蓋死特定格（如 S2 角區）。

### 關卡

| 關卡 | 戰術單元 | 正解概念 |
|------|----------|----------|
| D1 | Break the Press | 傳出壓力區 → 換邊 → 推進射門 |
| D2 | Overlap | 邊衛無球套邊 → 接球下底遠柱 |
| D3 | Underlap | 前腰肋部內切 → 直塞 → 遠柱 |
| D4 | Cut-back | 邊路推進 → 前鋒插上倒三角 → 射門 |
| D5 | Wall Pass | 傳牆 → 插上接回傳 → 傳邊射門 |
| D6 | Beat the DM | 撞牆繞后腰 → 高空吊前鋒 → 射門 |

**防守體系**：

| 關卡 | 防守類型 | 正解概念 |
|------|----------|----------|
| S1 | 高位逼搶 | 傳出雙逼搶 → 換邊 → 回傳射門 |
| S2 | 擺大巴 | 下底扯防線 → 倒三角 → 橫傳對側射門 |
| S3 | 四人盯人＋大閘 | 換邊 → 假跑拉開門側盯人 → 傳空當射門 |
| S4 | 中位防守 | 撞牆繞后腰 → 高空吊前鋒 → 射門 |
| S5 | 雙防中 | 撞牆繞雙后腰 → 高空吊前鋒 → 射門 |

CLI：

```bash
python play_defense.py D4
python play_defense.py S2 --demo
# lob A2   ← 高空傳球
# pass A2  ← 地滾傳球
# end      ← 結束進攻階段
```
